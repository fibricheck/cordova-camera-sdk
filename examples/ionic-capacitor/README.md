# FibriCheck Cordova Example

This example uses [Ionic](https://ionicframework.com/) as a cross-platform framework.

Execute the following commands to create an Android and iOS project
```
npm i -g @ionic/cli
npm install
ionic capacitor sync
```

For Android: 
```
ionic capacitor add android
ionic capacitor open android
```

For iOS: 
```
ionic capacitor add ios 
ionic capacitor open ios
```
